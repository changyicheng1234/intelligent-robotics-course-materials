## 🔒 访问限制

为了支持项目，浏览者需要先给仓库点 Star ⭐ 才能查看图片内容。

### ⚠️ 重要说明

**限制说明**：由于 GitHub Pages 是静态托管服务，图片文件本身是公开可访问的。如果用户知道图片的直接 URL，仍然可以直接访问。

**当前方案的作用**：
- ✅ 引导用户 Star 仓库
- ✅ 在正常浏览流程中隐藏图片
- ✅ 增加直接访问的难度
- ❌ **无法完全阻止**直接访问图片 URL

### 如何查看图片

**方法一：使用 Token 验证（推荐，更安全）**

1. 访问 [GitHub Pages 页面](https://changyicheng1234.github.io/intelligent-robotics-course-materials/)
2. 点击"使用 Token 验证"按钮
3. 按照提示创建 GitHub Personal Access Token
4. 输入 Token 进行验证
5. 验证成功后自动跳转并显示图片

**方法二：快速验证**

1. 访问 [GitHub Pages 页面](https://changyicheng1234.github.io/intelligent-robotics-course-materials/)
2. 点击"前往 GitHub 仓库"链接
3. 给仓库点 Star ⭐
4. 返回页面，点击"我已 Star，快速验证"按钮
5. 确认后即可查看所有图片
