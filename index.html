📝 操作步骤：

  1. 前往 GitHub 仓库 点击右上角 ⭐ Star
  2. 生成一个 GitHub Personal Access Token（点此创建）
    注：权限只需勾选 public_repo，Token 仅在你的浏览器本地使用，不会上传到任何服务器
  3. 点击下方按钮，输入 Token 进行验证
🔗 前往 GitHub 仓库（点 Star） 🔐 输入 Token 验证并查看例题
💡 Token 仅存储在你的浏览器中，不会发送到任何第三方服务器。
验证有效期 24 小时，过期后需重新验证。
